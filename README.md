# Beaver-CSE416

This repository is the Lifetime Financial Planner by team Beaver. This project is submitted in partial fulfillment of the course CSE 416.

## Required dependencies

This project is built using the MERN stack. This requires Nodejs and NPM to run.

## How to execute

1. Install dependencies
    1. Open command prompt.
    2. CD into the project's root directory.
    3. Run: npm run install-all

2. Create Environment Variables
    1. Create a .env file, place it in the backend directory.
    2. It should include all the fields specified in example_env.txt.   

3. Start backend
    1. Open command prompt.
    2. CD into the project's backend directory.
    3. Run: npm start
    4. This will run the server locally on your machine.

4. Start frontend
    1. Open command prompt.
    2. CD into the project's frontend directory.
    3. Run: npm start
    4. This will run the client locally on your machine. 

## Some notes

Uploaded YAML files are not stored in MongoDB, they are stored locally on the server, and they are not uploaded to the repository.
